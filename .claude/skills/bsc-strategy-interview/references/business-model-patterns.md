# 비즈니스 모델 패턴 카드 (The Business Model Navigator)

스위스 장크트갈렌 대학의 올리버 가스만(Oliver Gassmann) 교수 연구진이 정리한
프레임워크. 전 세계 비즈니스 모델의 상당수가 소수의 반복되는 패턴을
재조합한 것이라는 관찰에서 출발하며, "누구에게(Who) · 무엇을(What) ·
어떻게(How) · 왜=수익모델(Why)" 4가지 질문에 대한 답을 아래와 같은 패턴
카드에서 찾아 조합하도록 돕는다.

**정직성 주의**: 원 프레임워크는 55개 패턴으로 알려져 있다. 아래는 일반
지식을 바탕으로 최대한 복원한 **54개**이며, 정확한 이름·정의·사례가 필요한
실무(카드 구매, 출판물 인용 등)에는 원서 *The Business Model Navigator*나
공식 카드 세트를 반드시 대조 확인해야 한다. 마지막 1개는 정확히 특정할
자신이 없어 임의로 지어내지 않고 비워두었다 — 사용자가 원서/자료를 공유하면
그 항목을 채운다.

## 언제, 어떻게 쓰는가

- **먼저 들이밀지 않는다.** Socratic 원칙("먼저 답을 주지 않는다")을 그대로
  적용한다. [bmc-questions.md](bmc-questions.md) 클러스터 진행 중 사용자가
  "잘 모르겠다/막막하다"고 하거나, 명시적으로 "다른 방식이 있을까?"라고 물을
  때만 꺼낸다.
- 꺼낼 때도 정답처럼 제시하지 않는다. "이런 패턴들도 있는데, 우리 사업에
  이런 걸 접목하면 어떨까요?"처럼 발상을 촉발하는 질문으로 던지고, 채택
  여부는 전적으로 사용자가 판단하게 한다.
- 막힌 블록에 맞는 카테고리에서만 2~3개를 골라 보여준다. 54개를 한 번에
  나열하면 정보 과부하로 Socratic 대화의 리듬이 끊긴다 — 이 표는 인터뷰
  중 참조할 내부 카탈로그이지, 사용자에게 통째로 붙여넣을 메시지가 아니다.

## 대표 패턴 전체 목록 (54개)

### A. 가격·수익 모델 — 어떻게 돈을 버는가 ([수익원 블록](bmc-template.md)과 연결)

| 패턴 | 설명 | 예시 |
|---|---|---|
| 애드온 (Add-On) | 기본 서비스는 저렴하게, 옵션 추가 시마다 비용 청구 | 저가 항공사의 수하물·좌석 지정 요금 |
| 경매 (Auction) | 정가가 아니라 입찰로 가격이 결정되게 한다 | 프라이스라인의 "내가 원하는 가격 부르기" |
| 물물교환 (Barter) | 현금 대신 상품·서비스를 맞교환 | 미디어 광고 지면 ↔ 광고주 제품 교환 |
| 캐시 머신 (Cash Machine) | 공급사 결제 전에 고객 대금을 먼저 받아 음(-)의 운전자본을 만든다 | 델 컴퓨터의 선주문·후생산 |
| 정액제 (Flat Rate) | 사용량과 무관하게 고정 금액으로 무제한 이용 | 넷플릭스 |
| 프리미엄 (Freemium) | 기본 버전은 평생 무료로 진입 장벽을 낮추고, 고급 기능만 유료 | 스포티파이, 링크드인 |
| 히든 레비뉴 (Hidden Revenue) | 핵심 제품은 무료로 제공하고 제3자(광고주)에게서 수익을 낸다 | 무료 지상파 방송, 구글 검색 |
| 사용량 과금 (Pay per Use) | 쓴 만큼만 청구 | 클라우드 종량제 |
| 원하는 만큼 지불 (Pay What You Want) | 가격을 구매자가 스스로 정하게 한다 | 라디오헤드 인 레인보우스 앨범 |
| 면도기-면도날 (Razor and Blade) | 본체는 저가·손해 감수, 소모품에서 지속적 마진을 남긴다 | 질레트 면도기, 프린터-잉크 |
| 구매 대신 대여 (Rent Instead of Buy) | 소유권 이전 없이 사용권만 일정 기간 빌려준다 | 렌터카, 정수기 렌탈 |
| 수익 공유 (Revenue Sharing) | 파트너와 매출을 사전 정의된 비율로 나눈다 | 앱스토어 30% 수수료 구조 |
| 구독 (Subscription) | 정기 결제로 지속적 접근권을 판매 | 넷플릭스, SaaS 구독 |
| 저소득층 타겟 (Target the Poor) | 저소득 시장(BOP)을 낮은 단가·대량으로 공략 | 그라민은행 마이크로파이낸스 |
| 초고가 럭셔리 (Ultimate Luxury) | 압도적 희소성·품질로 최고가를 정당화 | 에르메스, 롤스로이스 |

### B. 가치 사슬·운영 — 어떻게 효율을 극대화하는가 ([핵심 활동·자원 블록](bmc-template.md)과 연결)

| 패턴 | 설명 | 예시 |
|---|---|---|
| 디지털화 (Digitalization) | 물리적 제품·프로세스를 디지털로 전환해 한계비용을 낮춘다 | 종이 문서 → 전자문서 SaaS |
| 직판 (Direct Selling) | 중간 유통 없이 제조사가 소비자에게 직접 판매 | D2C 브랜드 |
| 탈중개 (Disintermediation) | 기존 가치사슬의 중간 단계를 완전히 제거 | 델 컴퓨터 |
| 프랜차이징 (Franchising) | 브랜드·운영 노하우를 라이선스하고 로열티를 받는다 | 맥도날드 |
| 통합자 (Integrator) | 가치사슬 대부분 단계를 직접 수직계열화해 소유·통제 | 자라(디자인부터 매장까지 내재화) |
| 레이어 플레이어 (Layer Player) | 여러 산업의 가치사슬 중 한 층(레이어)만 전문화해 공급 | 결제대행사(PG) |
| 역량 재판매 (Make More of It) | 내부용으로 개발한 핵심 역량·인프라를 외부에 판매 | 아마존 AWS(원래 내부 인프라) |
| 대량 맞춤화 (Mass Customization) | 대량생산 효율을 유지하면서 개인 맞춤 옵션을 제공 | 나이키 바이 유(Nike By You) |
| 노프릴 (No Frills) | 부가서비스를 걷어내고 핵심 기능만 초저가로 | 저가 항공사 |
| 오픈 비즈니스 (Open Business) | 기술·소스를 공개해 생태계를 키운 뒤 주변 서비스로 수익 | 리눅스, 안드로이드 |
| 조정자 (Orchestrator) | 자산을 소유하지 않고 파트너 네트워크를 연결·조율 | 나이키(설계·마케팅만 직접, 생산은 전량 외주) |
| 역설계 (Reverse Engineering) | 경쟁 제품을 분해·분석해 유사 기능을 더 싸게 재현 | 제네릭 의약품 |
| 셀프서비스 (Self-Service) | 고객이 직접 일부 작업을 수행하게 해 비용을 낮춘다 | 이케아 조립가구, 셀프 계산대 |
| 솔루션 프로바이더 (Solution Provider) | 여러 제품·서비스를 하나의 원스톱 패키지로 묶는다 | IBM의 IT 통합 솔루션 |
| 수퍼마켓 (Supermarket) | 다양한 상품을 대량 매입해 낮은 마진·높은 회전으로 판매 | 월마트, 코스트코 |
| 화이트 라벨 (White Label) | 자사 생산 제품을 타사 브랜드로 판매하게 한다 | OEM 제조사 |

### C. 고객 관계·락인 ([고객 관계 블록](bmc-template.md)과 연결)

| 패턴 | 설명 | 예시 |
|---|---|---|
| 고객 로열티 (Customer Loyalty) | 포인트·마일리지로 재구매를 유도 | 항공 마일리지 프로그램 |
| 경험 판매 (Experience Selling) | 기능이 아니라 감정적 경험을 제품에 얹어 판매 | 스타벅스의 '제3의 공간' |
| 가용성 보장 (Guaranteed Availability) | 제품 자체가 아니라 "필요할 때 반드시 쓸 수 있음"을 판매 | 항공기 부품 24시간 가용성 계약 |
| 락인 (Lock-in) | 전환 비용을 높여 경쟁사로 이탈을 어렵게 만든다 | 애플 생태계 |
| 성과 기반 계약 (Performance-Based Contracting) | 사용량이 아니라 실제 성과·산출물에 따라 과금 | 롤스로이스 "Power by the Hour"(엔진 가동시간당 과금) |

### D. 플랫폼·네트워크 ([채널·파트너십 블록](bmc-template.md)과 연결)

| 패턴 | 설명 | 예시 |
|---|---|---|
| 제휴 (Affiliation) | 제3자가 고객을 유치해오면 수수료를 지급 | 제휴 마케팅 |
| 크라우드펀딩 (Crowdfunding) | 다수 대중에게서 소액씩 사전 자금을 모은다 | 킥스타터 |
| 크라우드소싱 (Crowdsourcing) | 문제 해결·콘텐츠 생산을 불특정 다수에게 개방 | 위키피디아 |
| 성분 브랜딩 (Ingredient Branding) | 부품·소재 브랜드를 완제품에 노출시켜 별도 가치를 인정받는다 | 인텔 인사이드 |
| 고객 데이터 활용 (Leverage Customer Data) | 축적된 고객 데이터 자체를 자산화해 수익 창출 | 데이터 기반 타겟 광고 |
| 피어투피어 (Peer-to-Peer) | 개인과 개인을 직접 연결하고 플랫폼은 중개 수수료만 취한다 | 에어비앤비, 우버 |
| 숍인숍 (Shop-in-Shop) | 자사 매장 일부를 타사에 임대해 시너지를 낸다 | 백화점 내 브랜드 매장 |
| 양면시장 (Two-Sided Market) | 서로 다른 두 고객군을 동시에 연결하고 양쪽/한쪽에서 과금 | 구글(검색 이용자 ↔ 광고주) |

### E. 발상의 전환·포지셔닝 — 경쟁 판도를 어떻게 바꾸는가 ([가치 제안 블록](bmc-template.md)과 연결)

| 패턴 | 설명 | 예시 |
|---|---|---|
| 아이키도 (Aikido) | 경쟁사의 가장 강력한 강점을 오히려 약점으로 뒤집는다 | 닌텐도 Wii — 고사양 그래픽 경쟁 대신 온 가족이 몸으로 즐기는 저사양 게임으로 시장을 뒤흔든 사례 |
| 푸시에서 풀로 (From Push to Pull) | 중앙 계획·강매 대신 실제 수요가 발생하는 지점에서 유연하게 대응 | 자라의 수요 기반 소량 다품종 생산 |
| 롱테일 (Long Tail) | 잘 팔리는 상위 20% 대신, 무한한 온라인 공간으로 하위 80% 틈새 상품을 모아 매출을 만든다 | 아마존 |
| 역혁신 (Reverse Innovation) | 신흥시장을 위해 먼저 개발한 저비용 혁신을 선진시장으로 역수출 | GE의 휴대용 초음파 기기 |
| 로빈후드 (Robin Hood) | 부유한 고객군의 높은 마진으로 저소득 고객군에게 낮은 가격을 보조 | 탐스슈즈(One for One), 와비파커 |
| 사용자 디자인 (User Design) | 최종 사양을 사용자가 직접 설계·주문 제작하게 한다 | 무신사 스탠다드 맞춤 굿즈, 나이키 바이 유 |

### F. 조달·소싱 ([핵심 자원 블록](bmc-template.md)과 연결)

| 패턴 | 설명 | 예시 |
|---|---|---|
| 이커머스 (E-Commerce) | 오프라인 유통망 없이 온라인 채널만으로 직접 거래 | 쿠팡 초기 모델 |
| 분할 소유 (Fractionalized Ownership) | 고가 자산을 여러 고객이 지분으로 나눠 소유하게 한다 | 넷제트(NetJets)의 전용기 공동소유 |
| 라이선스 (License) | 기술·지식재산권 사용권을 타사에 판매 | 특허 라이선싱 |
| 쓰레기의 현금화 (Trash to Cash) | 생산 부산물·폐기물을 재활용해 별도 수익원으로 전환 | 부산물 재판매(가죽 자투리 → 소품) |

## 핵심 사용법

창업·신사업 구상을 백지에서 시작하지 않고, 패턴 카드를 펼쳐놓고 "우리 사업에
'아이키도' 패턴을 접목하면 어떻게 될까?", "우리 제품을 '애드온' 모델로 바꿀
수 있을까?"처럼 강제로 조합해보며 발상하는 용도다. BMC 인터뷰 중에는 이
질문 형태 그대로, 사용자가 막힌 지점의 블록에 해당하는 카테고리(A~F)에서만
패턴을 골라 제시한다.
