# 의사결정 기록

Process GPT(본 제품 · process-gpt.io · 튜토리얼)에 관해 내린 결정을 날짜순으로 모읍니다. 직원 누구나 "무엇을 왜 그렇게 하기로 했는지"를 여기서 찾습니다. 코드 · 스펙 · PR 설명에는 결과가 남지만 결정과 이유는 흩어지기 쉬워 따로 기록합니다.

## 파일

- 한 달에 파일 하나: [2026-11.md](2026-11.md)
- 맨 아래 「결정 대기」 표에 아직 결정하지 않은 사항을 적습니다. 결정하면 해당 월의 파일로 옮깁니다.

## 항목 쓰는 법

```markdown
### D-<월일>-<번호> <결정을 한 줄로>
- **결정**: 무엇을 하기로(또는 하지 않기로) 했는가
- **이유**: 결정한 사람이 든 이유. 말한 그대로에 가깝게
- **세부(위임 판단)**: 결정한 사람이 맡긴 세부를 실무자가 정했으면 그 내용과 근거
- **상태**: 확정 · 반영(PR/커밋) · 진행 중 · 보류 · 뒤집음(→ 새 결정 번호)
```

- 각 묶음의 첫머리에 **결정한 사람**, **근거**(회의 · 검토 영상 · 메시지), **반영**(PR · 스펙 · 영상)을 적습니다.
- 결정을 바꾸면 기존 항목을 지우지 않습니다. 상태를 「뒤집음(→ D-…)」으로 바꾸고 새 항목을 씁니다.
- 실무자(사람이든 AI든)가 위임받아 정한 내용은 「위임 판단」으로 밝혀 결정한 사람이 나중에 다시 확인할 수 있게 합니다.
- 스펙(`openspec/`)은 "시스템이 어떻게 동작해야 하는가"를, 이 기록은 "누가 무엇을 왜 정했는가"를 적습니다. 결정이 동작을 바꾸면 두 곳에 함께 남깁니다.
