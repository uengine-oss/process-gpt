## Why

대화 맥락 라우터는 사용자의 최근 맥락 8개만 판단 모델에 보여 줬다. 한 채팅창을 몇 달 쓰는 사용자는 맥락이 수백 개로 쌓이는데, 그러면 두 가지가 동시에 나빠진다.

- **찾지 못한다**: 3주 전 "부가세 납부" 대화의 후속 메시지가 와도 그 대화가 최근 8개 밖이면 후보에 없어 새 주제로 판단된다.
- **다 넣을 수도 없다**: 선택지 문자(A~Z) 방식의 판단은 26개가 한계이고, 선택지가 늘수록 판단 지연이 커지고(측정 2~3초) 정확도도 떨어진다.

또 대화가 길어질수록 요약이 "최근 요청·답" 한 쌍으로 덮어써져 앞의 흐름이 사라지고, 오래된 맥락까지 같은 길이로 보여 주는 것은 낭비다.

같은 판단 계약(`POST /decide`)은 브라우저 에이전트의 짧고 잦은 판단(이 페이지가 아직 뜨는 중인가, 목표를 다 모았나)에도 쓸 수 있다. 지금은 그런 판단도 매 턴 화면을 보내는 큰 모델 호출로 처리한다.

## What Changes

- **후보 좁히기(모델 호출 없음)**: 잠든 맥락(30일) 제외 → 최근 200개 + 메시지 단어로 저장소 검색 → 단어 겹침·의미 유사도(선택)·최근성 점수로 6개 이하. 진행 중 작업과 가장 최근 2개는 항상 남기고, 같은 제목의 반복 업무는 한 자리만.
- **나이에 따른 압축**: 하루 이내 160자, 일주일 이내 100자, 그 이후 60자. 대화 이력 전체는 넘기지 않는다.
- **요지 누적**: 요약을 바꿀 때 이전 요청을 단어 요지(`gist`, 120자)에 접어 넣는다.
- **근거 없는 판단 모델 선택의 재판단**: 판단 모델이 고른 맥락에 메시지와 겹치는 단어도, 의미 유사도도 없으면 판단 모델을 건너뛰고 다음 전략으로 다시 판단한다(`Decider.decide(skip=)`).
- **참조 판단 서버의 임베딩**: `EMBED_MODEL`(bge-m3)로 OpenAI 형식 `/embeddings` 제공. 라우터는 `ROUTER_EMBED_URL` 로 이 서버나 OpenAI 등 아무 OpenAI 형식 엔드포인트를 쓴다.
- **브라우저 에이전트 판단 게이트(pgpt-pro)**: 새 페이지마다 상태 판단(로딩이면 큰 모델 없이 기다림, 무인 실행의 로그인 벽·캡차면 미리 안내), 사실 기록마다 목표 달성 판단(확실하면 조기 종료), 측정 기록.

## Capabilities

### New Capabilities

- `pgpt-pro_browser-decision-gates`: 페이지 상태 게이트, 목표 달성 게이트와 조기 종료, 게이트 효과 측정.

### Modified Capabilities

- `context-router_conversation-routing`: 후보 좁히기, 잠든 맥락 제외와 오래된 맥락 검색, 나이에 따른 압축, 요지 누적, 근거 없는 선택의 재판단 추가.
- `context-router_decision-strategies`: 전략 건너뛰기(`skip`), 참조 판단 서버의 임베딩 엔드포인트 추가.

## Impact

- **데이터**: `context_threads.gist` 열 추가(`sql/002_context_gist.sql`).
- **설정**: `ROUTER_TOP_K`, `ROUTER_KEEP_RECENT`, `ROUTER_DORMANT_DAYS`, `ROUTER_SCAN`, `ROUTER_HOT_HOURS`, `ROUTER_WARM_DAYS`, `ROUTER_EVIDENCE_SIM`, `ROUTER_EMBED_URL/KEY/MODEL`(선택), 판단 서버 `EMBED_MODEL`(선택), pgpt-pro `PRO_BROWSER_GATES`.
- **호환성**: 임베딩을 설정하지 않으면 단어 겹침만으로 동작한다. 판단 계약과 라우팅 응답 형식은 그대로다.
