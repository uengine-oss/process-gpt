# WMS 품질 검사·처분 명세

## ADDED Requirements

### Requirement: 품질 계획과 샘플링 (WMS-QA-001)
시스템은 상품, 공급사, 창고, 수량과 위험등급에 따라 검사 항목, 샘플 수와 판정 기준을 SHALL 결정한다.

#### Scenario: 입고 검사 생성
- **GIVEN** receipt line이 품질 규칙과 일치한다
- **WHEN** 입고 수량이 확정된다
- **THEN** 시스템은 적용 규칙 버전, 샘플 수, 검사 항목과 담당 역할이 있는 검사를 생성한다

### Requirement: 검사 결과와 증빙 (WMS-QA-002)
시스템은 검사 항목별 측정값, 합격 여부, 검사자, 시각, 메모와 사진·문서 증빙을 SHALL 보존한다.

#### Scenario: 필수 증빙 누락
- **GIVEN** 불합격 판정에 사진과 사유가 필수인 규칙이 있다
- **WHEN** 검사자가 증빙 없이 불합격 확정을 요청한다
- **THEN** 시스템은 판정 확정을 거부하고 누락 항목을 반환한다

### Requirement: 검사 중 재고 격리 (WMS-QA-003)
시스템은 검사 대기·진행·불합격 수량을 HOLD 또는 QC 상태로 유지하여 예약과 출고를 SHALL 차단한다.

#### Scenario: 검사 수량 예약 시도
- **GIVEN** 상품 수량이 QC_PENDING 상태이다
- **WHEN** 출고 할당이 해당 수량을 예약하려 한다
- **THEN** 시스템은 해당 수량을 후보에서 제외한다

### Requirement: 부분 합격 판정 (WMS-QA-004)
시스템은 입고 line을 합격, 불합격과 추가검사 수량으로 분할하고 합계가 검사 대상 수량과 일치하도록 SHALL 검증한다.

#### Scenario: 일부 합격
- **GIVEN** 검사 대상이 100 EA이다
- **WHEN** 검사자가 합격 90, 불합격 10으로 판정한다
- **THEN** 시스템은 합격 90에 putaway 대기를 생성하고 불합격 10을 격리한다
- **AND** 원래 receipt와 lot 계보를 모두 보존한다

### Requirement: 불합격 처분 (WMS-QA-005)
시스템은 불합격 재고에 폐기, 공급사 반품, 재작업 또는 추가검사의 명시적 처분과 승인을 SHALL 요구한다.

#### Scenario: 폐기 처분
- **GIVEN** 불합격 수량이 HOLD 위치에 있고 사용자가 폐기 권한을 가진다
- **WHEN** 사유·수량·증빙이 있는 폐기 처분이 승인된다
- **THEN** 시스템은 SCRAP 위치로 원자적 이동을 기록한다
- **AND** PO, receipt, 검사와 폐기 movement를 상호 연결한다

#### Scenario: 공급사 반품
- **GIVEN** 불합격품의 공급사와 원 PO를 식별할 수 있다
- **WHEN** 반품 처분이 승인된다
- **THEN** 시스템은 supplier return 문서와 출고 작업을 생성한다
- **AND** 반품 완료 전 수량을 available로 전환하지 않는다

### Requirement: 합격 후 가용 전환 (WMS-QA-006)
시스템은 품질 합격만으로 보관 재고를 가용화하지 않고 적치 완료 후에 SHALL 가용화한다.

#### Scenario: 합격 후 적치 대기
- **GIVEN** 검사 수량이 합격 판정을 받았다
- **WHEN** 아직 최종 보관 위치로 이동하지 않았다
- **THEN** 시스템은 PUTAWAY_PENDING 상태와 적치 작업을 생성한다
- **AND** 해당 수량은 출고 가용 수량에 포함하지 않는다
