# agent-feedback_skill-contribution-tracking — 스킬별 사람 기여 이력 추적

## ADDED Requirements

### Requirement: 스킬 생성·수정 시 기여자가 자동으로 기록된다
스킬이 새로 생성되거나 기존 스킬의 내용이 수정될 때, 그 작업을 수행한 사람이 해당 스킬의 기여 이력에 자동으로 추가되어야 한다(SHALL). 기여 이력 각 항목에는 기여자, 기여 시각, 기여 유형(생성 또는 수정)이 포함되어야 한다(MUST).

#### Scenario: 신규 스킬 생성 시 기여 기록
- **WHEN** 사람이 새 스킬을 생성하면
- **THEN** 그 스킬의 기여 이력에 해당 사람이 기여 유형 "생성"으로 기록된다

#### Scenario: 기존 스킬 수정 시 기여 기록
- **WHEN** 사람이 기존 스킬의 내용을 수정하면
- **THEN** 그 스킬의 기여 이력에 해당 사람이 기여 유형 "수정"으로 추가된다

### Requirement: 제안 승인 흐름을 통한 스킬 변경도 기여로 기록된다
스킬 생성·수정 제안이 승인되어 반영될 때, 그 제안을 승인한 사람과 원 제안자가 모두 해당 스킬의 기여 이력에 기록되어야 한다(SHALL). 제안이 거부된 경우에는 기여 이력에 추가되지 않아야 한다(MUST NOT).

#### Scenario: 승인된 제안의 기여 기록
- **WHEN** 스킬 수정 제안이 승인되어 스킬에 반영되면
- **THEN** 그 스킬의 기여 이력에 제안자와 승인자가 함께 기록된다

#### Scenario: 거부된 제안은 기록되지 않음
- **WHEN** 스킬 수정 제안이 거부되면
- **THEN** 그 스킬의 기여 이력에 해당 제안과 관련된 항목이 추가되지 않는다

### Requirement: 스킬별 기여자 목록과 기여 비중을 조회할 수 있다
`GET /api/skills/{id}/contributors?tenant_id=`는 지정 스킬에 대한 기여자 목록을 반환해야 한다(SHALL). 각 기여자 항목에는 기여 건수와 해당 스킬의 전체 기여 건수 대비 상대적 기여 비중(백분율)이 포함되어야 한다(MUST). 기여 이력이 없는 스킬을 조회하면 빈 목록이 오류 없이 반환되어야 한다(MUST). 존재하지 않는 스킬 id에 대해서는 404 오류를 반환해야 한다(MUST).

#### Scenario: 여러 기여자가 있는 스킬 조회
- **WHEN** 두 명 이상의 사람이 기여한 스킬의 id로 기여자 목록을 조회하면
- **THEN** 각 기여자의 기여 건수와, 전체 대비 상대적 기여 비중이 함께 반환된다

#### Scenario: 기여 이력이 없는 스킬 조회
- **WHEN** 아직 아무도 기여하지 않은 스킬의 id로 기여자 목록을 조회하면
- **THEN** 빈 목록이 오류 없이 반환된다

#### Scenario: 존재하지 않는 스킬 조회
- **WHEN** 존재하지 않는 스킬 id로 기여자 목록을 조회하면
- **THEN** 404 오류가 반환된다
