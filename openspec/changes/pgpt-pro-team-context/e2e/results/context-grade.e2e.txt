 1. 이도윤 내 맥락 3개: 경쟁 서비스 동향(요약 공개 · 팀), 개인 학습 메모(비공개), 사내 교육 자료 정리(제목 공개) · 기본 요약 공개 · 팀
 2. 미리보기 요약 공개 · 회사: 요약 박하늘·윤서진·정하은·최유나 (새로 정하은·최유나) / 원문 0명 / 제목 0명
 3. 미리보기 제목 공개: 요약 박하늘(전략팀장), 윤서진(관리자) · 덜 보게 됨 없음
 4. 최유나가 이도윤 맥락을 바꾸려 함 → 404 「없는 맥락입니다」 (없는 맥락 404 「없는 맥락입니다」)
 5. 이도윤 「경쟁 서비스 동향」 → 요약 공개 · 회사: 「「경쟁 서비스 동향」을 요약 공개 · 회사로 바꿨습니다」
 6. 정하은이 다시 열면 깊이 summary — 근거 요약 공개 · 회사 범위
 7. 관리자 윤서진이 이도윤 「개인 학습 메모」(비공개)를 id 로 → 404 「없는 맥락입니다」
 8. 최유나 민감 표시 제안: 「연봉 협상 준비」(연봉)
 9. 최유나 승인 → confirmed · 「민감 항목이 되었습니다」
10. 민감 항목을 전체 공개로 → 422 「민감 항목은 전체 공개로 열 수 없습니다」
11. 민감 뒤 깊이: 윤서진(관리자) title · 박하늘(다른 팀장) title · 정하은(같은 팀) summary
12. 「제안서 표준 목차」(전체 공개 · 부서)에 민감 표시 → 요약 공개 · 부서 · 「민감 항목이 되었습니다. 전체 공개였으므로 요약 공개 · 부서로 좁혔습니다」
13. 최유나가 「연봉 협상 준비」 표시를 무시 → 「민감 표시 제안을 무시했습니다(다시 제안하지 않습니다)」 · 다시 훑어도 제안 0건
14. 이도윤 「사내 교육 자료 정리」 목적에 「급여」 → 훑기: 제안 「사내 교육 자료 정리」(급여, new=true)
15. 이도윤의 「내 맥락을 본 기록」: 정하은 · 요약 · 2번 · 요약 공개 · 회사 범위 / 최유나의: 이도윤 · 원문 · 전체 공개 · 부서 범위
16. 정하은 기본 등급 → listed/team (자동 허용 규칙 3줄 그대로)
