## ADDED Requirements

### Requirement: 사용자가 열어 둔 문서 찾기

`office_live_documents`는 호출한 사용자가 지금 편집기에 열어 둔 문서만 돌려줘야 한다(SHALL). 항목마다 `session_id`, `editor`, `file_name`, `file_url`, `read_only`, `ready`가 있어야 한다(SHALL). 다른 사용자가 연 문서는 보이지 않아야 한다(SHALL). 실시간 도구는 워드와 엑셀 편집기에서 동작한다.

#### Scenario: 업무 화면에 연 초안
- **GIVEN** 담당자가 업무 화면에서 워드 초안을 편집기로 열어 두었다
- **WHEN** 담당자의 채팅 에이전트가 열린 문서 목록을 부른다
- **THEN** 그 초안이 세션 하나로 나오고, 다른 사용자가 연 문서는 나오지 않는다

#### Scenario: 열린 문서가 없음
- **WHEN** 아무 문서도 열지 않은 사용자의 에이전트가 목록을 부른다
- **THEN** 빈 목록이 돌아온다

### Requirement: 열린 문서의 지금 내용 읽기

`office_live_read`는 열린 문서의 지금 내용을 저장 전 편집까지 포함해 돌려줘야 한다(SHALL). 워드는 블록 번호가 붙은 본문을, 엑셀은 시트 요약이나 요청한 셀 값을 돌려줘야 한다(SHALL).

#### Scenario: 저장 전 내용
- **GIVEN** 사용자가 문서에 저장하지 않은 문단을 써 두었다
- **WHEN** 에이전트가 열린 문서를 읽는다
- **THEN** 저장하지 않은 그 문단이 결과에 있다

### Requirement: 사람이 보는 앞에서 쓰고 바꾸기

`office_live_write`는 열린 워드 문서에 내용을 넣어야 하며(SHALL), 위치(`after_block_index`)가 없으면 문서 끝에 넣어야 한다(SHALL). `office_live_replace`는 블록 범위(`start_block_index`~`end_block_index`) 또는 글(`match_text`, 그 글이 든 첫 블록)로 바꿀 곳을 찾아 바꿔야 한다(SHALL). `match_text`가 든 블록이 없으면 아무것도 바꾸지 않고 오류를 돌려줘야 한다(SHALL). 변경은 사용자가 보고 있는 편집기에 바로 나타나야 하며(SHALL), 사용자의 업무 화면에는 에이전트가 무엇을 하는지 알림("에이전트가 내용을 바꾸는 중 · …")이 떠야 한다(SHALL).

#### Scenario: 빈칸 채우기를 지켜봄
- **GIVEN** 담당자가 "(작성 예정)" 자리가 세 곳인 출장 결과 보고서를 업무 화면에서 열어 두었다
- **WHEN** 담당자가 채팅에서 에이전트에게 출장 내용을 알려 주고 열어 둔 보고서를 채워 달라고 한다
- **THEN** 담당자의 편집기에 문단이 차례로 들어오고, 알림이 뜨며, 세 자리가 모두 채워지고 제목은 바뀌지 않는다

#### Scenario: 글로 찾을 자리가 없음
- **WHEN** 에이전트가 문서에 없는 글을 `match_text`로 바꾸려 한다
- **THEN** 문서는 바뀌지 않고, 지금 내용을 다시 확인하라는 오류가 돌아온다

#### Scenario: 채팅 문서 패널에서 지켜봄
- **GIVEN** 채팅 옆 문서 패널에 에이전트가 고친 워드 문서가 열려 있다
- **WHEN** 사용자가 채팅에서 그 문서의 빈칸을 채워 달라고 한다
- **THEN** 같은 화면의 문서 패널에 내용이 채워진다

### Requirement: 열린 문서를 저장하기

`office_live_save`는 열린 문서를 저장해 원본 옆에 편집본을 올리고 그 `file_url`을 돌려줘야 한다(SHALL). 업무 화면의 첨부는 그 편집본으로 바뀌어야 한다(SHALL). 미리보기로 연 문서는 저장하지 않고 오류를 돌려줘야 한다(SHALL).

#### Scenario: 에이전트가 저장
- **WHEN** 에이전트가 빈칸을 채운 뒤 저장한다
- **THEN** 편집본 주소가 돌아오고, 담당자의 첨부 카드가 "편집본 · 다운로드"로 바뀐다

#### Scenario: 미리보기 문서
- **WHEN** 에이전트가 미리보기로 열린 문서를 저장하려 한다
- **THEN** 저장되지 않고 오류가 돌아온다

### Requirement: 닫혔거나 준비 중인 문서

닫힌 세션이나 다른 사용자의 세션을 가리키면 도구는 문서를 찾지 못했다는 오류를 돌려줘야 한다(SHALL). 아직 열리는 중인 문서에는 잠시 뒤 다시 시도하라는 오류를 돌려줘야 하며(SHALL), 편집기가 60초 안에 답하지 않으면 시간 초과 오류를 돌려줘야 한다(SHALL).

#### Scenario: 사용자가 편집기를 닫음
- **GIVEN** 에이전트가 세션을 받은 뒤 사용자가 편집기를 닫았다
- **WHEN** 에이전트가 그 세션에 쓰려 한다
- **THEN** 열린 문서를 찾지 못했다는 오류가 돌아오고, 목록을 다시 확인하라고 안내한다
