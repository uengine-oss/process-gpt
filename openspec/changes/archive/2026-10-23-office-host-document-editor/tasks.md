## 1. 문서 편집 백엔드(office-host)

- [x] 1.1 이음오피스 편집기 8종을 포크 수정 없이 웹에서 제공(`electron` 대체 모듈, 편집기 화면·문서 바이트·IPC 경로) — 원본 형식 그대로 열기
- [x] 1.2 저장 감지 → 원본 옆 편집본 업로드 → 업무 화면에 새 주소 알림. 편집본을 다시 고쳐도 이름이 겹치지 않음 — 저장하면 원본 옆에 편집본을 남기기
- [x] 1.3 미리보기 세션은 업로드하지 않음 — 미리보기는 저장해도 업무에 올리지 않기
- [x] 1.4 토큰 확인, 허락된 출처, 작업 폴더 밖 경로 거절 — 로그인한 사용자와 허락된 문서만
- [x] 1.5 빌드 때 제품 이름·AI 그림 교체, 고지 페이지(`/office/licenses/`) — 제품 이름과 오픈소스 고지
- [x] 1.6 Docker 이미지(엑셀 사이드카는 자식 프로세스) 빌드와 기동 확인
