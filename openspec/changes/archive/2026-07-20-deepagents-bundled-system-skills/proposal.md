## Why

process-gpt는 지금까지 "테넌트 스킬"만 일급으로 다뤘다 — 각 테넌트가 자신의
스킬을 `POST /skills/upload`로 개별 업로드해야만 그 테넌트의 채팅에서 쓸 수
있었다. 모든 테넌트가 공통으로 써야 하는 process-gpt 자체 제공 "시스템
스킬"(예: 균형성과표 전략 인터뷰)을 전역으로 노출할 방법은 `SKILL_REPO_URLS`
환경변수로 Git 원격 저장소를 등록해 서버가 매 실행마다 네트워크로 fetch하는
경로뿐이었다. 이 경로는 인터넷 접속이 없는 폐쇄망/설치형(on-prem) 배포에서
동작하지 않는다 — 심지어 기본 제공 번들(`anthropics-skills`)조차 최초 기동 시
바깥 Git 호스트 접속에 실패하면 예외 없이 조용히 스킬 0개로 폴백한다. 모든
테넌트가 네트워크·Git 접속과 무관하게 공통으로 접근할 수 있는 시스템 스킬
제공 경로가 필요했다.

## What Changes

- deepagents 서비스 저장소에 Docker 이미지 빌드에 그대로 포함되는 로컬 번들
  스킬 디렉토리(`system-skills/process-gpt-system/`)를 추가한다.
- 서버 기동 시점과 매 채팅 실행 시작 시점에, 이 번들을 스킬 루트의
  `process-gpt-system` 컬렉션으로 동기화(시딩)한다 — 순수 로컬 파일 복사만
  사용하며 어떤 네트워크 호출도 필요로 하지 않는다.
- 스킬 로더가 `process-gpt-system` 컬렉션을 Git 연동 설정(`SKILL_REPO_URLS`)
  여부와 무관하게 항상 "전역 컬렉션"으로 인식하도록 확장한다 — 어떤 테넌트든
  한 번도 업로드하지 않아도 스킬 목록·채팅에서 즉시 사용할 수 있다.
- 이 새 전역 시스템 스킬 컬렉션의 첫 항목으로 균형성과표(BSC) Socratic 전략
  인터뷰 스킬(`bsc-strategy-interview`)을 포함시킨다.

## Capabilities

### New Capabilities
- `deepagents_bundled-system-skills`: process-gpt가 직접 제공하는 시스템
  스킬을 테넌트별 업로드나 Git/네트워크 접속 없이 모든 테넌트에 공통으로
  노출하는 기능. 이미지 번들 → 로컬 시딩 → 전역 컬렉션 인식 → 테넌트 무관
  노출까지의 계약을 다룬다.

## Impact

- **서비스**: `services/deepagents` — 스킬 소스 디렉토리 스캔 로직, 채팅
  실행기, 서버 기동 절차에 로컬 시딩 단계가 추가된다.
- **배포**: 폐쇄망/설치형(on-prem) 배포를 포함한 모든 배포 환경에서 시스템
  스킬이 100% 로컬 이미지 콘텐츠만으로 모든 테넌트에 제공된다. 기존 Git
  기반 전역 컬렉션(`anthropics-skills`) 경로는 변경하지 않는다(순수 추가이며
  회귀 없음).
- **테넌트 데이터**: 테넌트별 업로드 스킬 저장 경로와 겹치지 않으므로 기존
  테넌트가 개별 업로드한 스킬에는 영향이 없다. 동일 이름의 테넌트 업로드
  스킬이 있으면 테넌트 스킬이 우선한다(테넌트 커스터마이징 허용).
- **범위 밖**: 개별 시스템 스킬의 대화 내용(어떤 질문을 어떤 순서로 하는가
  등)은 이 변경의 범위가 아니다 — 각 스킬 정의 파일(SKILL.md 및 참고 문서)
  콘텐츠로 관리된다.
