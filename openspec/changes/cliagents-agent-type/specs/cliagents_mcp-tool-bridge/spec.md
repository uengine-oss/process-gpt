## ADDED Requirements

### Requirement: ProcessGPT 도구의 MCP 노출
시스템은 프로세스 조회·폼 처리·지식 검색·문서 생성 등 ProcessGPT 도구를 MCP 서버로 등록해 CLI 에이전트가 사용할 수 있게 해야 한다(SHALL). 등록은 업무 실행 전에 완료되어야 하며, 등록 실패 시 어떤 도구가 사용 불가한지 실행 기록에 남겨야 한다(SHALL).

#### Scenario: 실행 전 도구 등록
- **WHEN** CLI 에이전트 업무 실행이 시작되면
- **THEN** ProcessGPT MCP 서버가 해당 실행에 등록되어 에이전트가 프로세스·폼·지식 도구를 호출할 수 있다

#### Scenario: 도구 등록 실패
- **WHEN** MCP 서버 등록이 실패하면
- **THEN** 실행 기록에 사용 불가한 도구 목록과 사유가 남고, 사용자에게 도구 없이 진행되었음이 보고된다

### Requirement: 등록의 멱등성과 사용자 설정 보존
시스템의 MCP 등록은 반복 실행해도 항목이 중복되지 않아야 하며(SHALL NOT), 사용자가 직접 추가한 다른 MCP 등록을 삭제하거나 덮어쓰지 않아야 한다(SHALL NOT).

#### Scenario: 반복 등록
- **WHEN** 같은 워크스페이스에서 업무를 여러 번 실행하면
- **THEN** MCP 등록 항목은 한 번만 존재하고 중복 항목이 생기지 않는다

#### Scenario: 사용자 등록 보존
- **WHEN** 워크스페이스에 사용자가 직접 등록한 MCP 서버가 있는 상태로 실행이 시작되면
- **THEN** 사용자의 등록은 그대로 유지되고 ProcessGPT 서버만 추가된다

### Requirement: 등록 범위 격리
MCP 등록 범위가 사용자 전역인 CLI 의 경우, 시스템은 실행 단위로 설정 홈을 격리해 다른 테넌트·다른 실행의 등록과 섞이지 않게 해야 한다(SHALL). 격리에 실패하면 실행을 진행하지 않아야 한다(SHALL NOT).

#### Scenario: 전역 등록 CLI 의 동시 실행
- **WHEN** 등록 범위가 사용자 전역인 CLI 로 서로 다른 테넌트의 업무가 동시에 실행되면
- **THEN** 각 실행은 자신에게 등록된 도구만 보고, 다른 테넌트의 도구나 자격 증명에 접근할 수 없다

#### Scenario: 격리 실패
- **WHEN** 실행 단위 설정 홈을 준비할 수 없으면
- **THEN** 업무는 실행되지 않고 격리 실패 사유로 실패 처리된다

### Requirement: 도구 사용 가시성
시스템은 CLI 에이전트가 호출한 도구의 이름과 시작·종료를 실행 진행 정보로 노출해야 한다(SHALL).

#### Scenario: 도구 호출 표시
- **WHEN** 에이전트가 실행 중 ProcessGPT 도구를 호출하면
- **THEN** 진행 표시에 해당 도구의 실행 시작과 종료가 나타나고, 사용자는 어떤 도구가 쓰였는지 확인할 수 있다
