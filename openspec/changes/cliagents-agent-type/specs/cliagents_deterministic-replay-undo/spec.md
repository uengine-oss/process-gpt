## ADDED Requirements

### Requirement: 재실행 가능한 변경 기록
시스템은 CLI 에이전트 실행 중 발생한 외부 변경을 재실행·되돌리기가 가능한 형태로 기록해야 한다(SHALL). 기록 대상은 ProcessGPT 도구를 통해 수행된 변경 작업과 작업 디렉터리 파일의 변경 전·후 상태이며, 기록 범위 밖의 변경은 재실행 대상이 아님을 명시해야 한다(SHALL).

#### Scenario: 도구 기반 변경 기록
- **WHEN** 에이전트가 ProcessGPT 도구로 데이터를 생성하거나 수정하면
- **THEN** 해당 호출의 대상과 입력, 결과가 재실행 가능한 기록으로 남는다

#### Scenario: 파일 변경 기록
- **WHEN** 에이전트가 작업 디렉터리의 파일을 생성·수정·삭제하면
- **THEN** 변경 전후 상태가 기록되어 되돌리기의 근거가 된다

### Requirement: 동일 조건 재실행
시스템은 기록된 실행에 대해 동일한 입력과 동일한 순서로 변경 작업을 다시 수행하는 재실행을 제공해야 한다(SHALL). 재실행은 모델을 다시 호출하지 않고 기록된 변경만 적용해야 한다(SHALL NOT re-invoke).

#### Scenario: 기록 기반 재실행
- **WHEN** 사용자가 이전 실행의 재실행을 요청하면
- **THEN** 기록된 변경 작업이 같은 순서로 적용되고, 모델 호출로 인한 결과 변동이 발생하지 않는다

#### Scenario: 재실행 중 실패
- **WHEN** 재실행 도중 어떤 변경 작업이 실패하면
- **THEN** 재실행이 중단되고 어디까지 적용되었는지 사용자에게 보고된다

### Requirement: 되돌리기
시스템은 기록된 실행의 변경을 역순으로 취소하는 되돌리기를 제공해야 한다(SHALL). 되돌릴 수 없는 변경이 포함된 경우 그 항목을 명시하고 나머지에 대해서만 되돌려야 한다(SHALL).

#### Scenario: 실행 되돌리기
- **WHEN** 사용자가 이전 실행의 되돌리기를 요청하면
- **THEN** 기록된 변경이 역순으로 취소되고, 작업 디렉터리 파일이 변경 전 상태로 복원된다

#### Scenario: 되돌릴 수 없는 변경 포함
- **WHEN** 외부에 되돌릴 수 없는 부수효과가 포함된 실행을 되돌리려 하면
- **THEN** 되돌릴 수 없는 항목이 사용자에게 명시되고, 되돌릴 수 있는 항목만 복원된다

### Requirement: 재실행 범위의 한계 표시
시스템은 기록 범위 밖(에이전트 내장 도구가 작업 디렉터리 밖에서 수행한 변경 등)이 감지된 실행에 대해 완전 재실행이 불가함을 표시해야 한다(SHALL).

#### Scenario: 범위 밖 변경이 감지된 실행
- **WHEN** 상향된 권한으로 실행되어 기록 범위 밖 변경이 발생한 실행을 재실행하려 하면
- **THEN** 부분 재실행만 가능함이 표시되고, 어떤 부분이 재현되지 않는지 안내된다
