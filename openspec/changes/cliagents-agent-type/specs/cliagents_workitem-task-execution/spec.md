## ADDED Requirements

### Requirement: CLI 에이전트 오케스트레이션으로 지정된 업무 실행
시스템은 오케스트레이션 값이 `cliagents` 인 워크아이템을 폴링해 담당 CLI 에이전트에게 위임 실행하고, 실행 시작·진행·종료 상태를 워크아이템에 반영해야 한다(SHALL). 다른 오케스트레이션 값의 워크아이템은 잡지 않아야 한다(SHALL NOT).

#### Scenario: 대기 중인 CLI 에이전트 업무를 집어 실행한다
- **WHEN** 오케스트레이션 `cliagents` 와 실행 CLI 가 지정된 워크아이템이 실행 대기 상태로 등록되면
- **THEN** 서비스가 해당 워크아이템을 점유해 실행 중 상태로 바꾸고, 담당자·업무 설명·입력 데이터를 실행 컨텍스트로 사용한다

#### Scenario: 다른 오케스트레이션 업무는 건드리지 않는다
- **WHEN** 오케스트레이션이 `deepagents` 또는 `langchain-react` 인 워크아이템이 대기 중이면
- **THEN** CLI 에이전트 서비스는 그 워크아이템의 상태를 변경하지 않는다

### Requirement: 업무 실행 결과 저장 모드
시스템은 업무에 설정된 실행 모드에 따라 결과를 저장해야 한다(SHALL). 초안 모드에서는 담당자 검토를 위한 초안 상태로 저장하고, 완료 모드에서는 업무를 완료 상태로 전이시켜야 한다(SHALL).

#### Scenario: 초안 모드 실행 결과
- **WHEN** 초안 모드로 설정된 업무 실행이 성공적으로 끝나면
- **THEN** 실행 결과가 초안으로 저장되고 업무는 담당자 확인을 기다리는 상태가 되며, 담당자에게 확인 요청이 전달된다

#### Scenario: 완료 모드 실행 결과
- **WHEN** 완료 모드로 설정된 업무 실행이 성공적으로 끝나면
- **THEN** 실행 결과가 업무 산출물로 저장되고 업무가 완료 상태로 전이된다

### Requirement: 출력 형식 계약 준수
업무에 출력 형식(폼 필드, 결과 스키마)이 정의되어 있으면, 시스템은 CLI 에이전트에게 그 형식을 지시하고 최종 산출물을 해당 형식으로 저장해야 한다(SHALL). 형식에 맞지 않는 산출물은 실패로 보고해야 하며, 임의로 비어 있는 값으로 채워 저장하지 않아야 한다(SHALL NOT).

#### Scenario: 정의된 출력 형식대로 저장
- **WHEN** 업무에 출력 필드가 정의되어 있고 실행이 끝나면
- **THEN** 각 출력 필드에 대응하는 값이 저장되고, 원문 텍스트도 함께 보존된다

#### Scenario: 출력 형식 불일치
- **WHEN** 최종 산출물이 정의된 출력 형식으로 해석되지 않으면
- **THEN** 업무는 실패로 기록되고 실패 사유에 형식 불일치가 명시되며, 부분 결과는 담당자가 볼 수 있도록 남는다

### Requirement: 실행 실패와 타임아웃 보고
시스템은 CLI 프로세스가 비정상 종료하거나 실행 제한 시간을 초과하면 업무를 실패로 기록하고, 사용자가 조치할 수 있는 사유(미설치, 미인증, 권한 거부, 타임아웃, 실행 오류)를 남겨야 한다(SHALL).

#### Scenario: CLI 실행 오류
- **WHEN** CLI 프로세스가 오류 코드로 종료되면
- **THEN** 업무가 실패 상태로 기록되고, 실패 사유와 마지막 출력이 담당자에게 보인다

#### Scenario: 실행 제한 시간 초과
- **WHEN** 실행이 설정된 제한 시간을 초과하면
- **THEN** 실행이 중단되고 업무는 타임아웃 사유로 실패 처리되며, 그때까지의 산출물과 파일은 보존된다

### Requirement: 실행 취소
시스템은 진행 중인 업무 실행에 대한 취소 요청을 받으면 CLI 프로세스를 종료하고, 업무를 취소 상태로 되돌려야 한다(SHALL). 취소 후 남은 프로세스나 점유 상태가 남아 있지 않아야 한다(SHALL NOT).

#### Scenario: 실행 중 업무 취소
- **WHEN** 사용자가 진행 중인 CLI 에이전트 업무를 취소하면
- **THEN** 실행 프로세스가 종료되고 업무는 재실행 가능한 상태로 되돌아가며, 진행 중 표시가 해제된다

### Requirement: 동시 실행 상한
시스템은 동시에 실행 중인 CLI 프로세스 수의 상한을 설정으로 가져야 하며(SHALL), 상한에 도달하면 새 워크아이템을 점유하지 않아야 한다(SHALL NOT).

#### Scenario: 상한 도달 시 대기
- **WHEN** 동시 실행 상한만큼 업무가 실행 중이고 새 워크아이템이 대기 중이면
- **THEN** 새 워크아이템은 점유되지 않고 대기 상태를 유지하며, 실행 슬롯이 비면 처리된다
