## ADDED Requirements

### Requirement: 오케스트레이션 선택 시 실행 CLI 지정
시스템은 오케스트레이션 목록에 `cliagents` 항목 하나를 제공하고, 이 항목을 선택했을 때 실행 CLI(`claude-code`, `codex`)를 별도 값으로 지정하도록 해야 한다(SHALL). CLI 별로 오케스트레이션 항목을 늘리지 않아야 한다(SHALL NOT).

#### Scenario: CLI 선택 후 저장
- **WHEN** 사용자가 업무 또는 에이전트 설정에서 오케스트레이션 `cliagents` 를 고르고 실행 CLI 를 선택하면
- **THEN** 오케스트레이션 값과 선택된 CLI 값이 함께 저장되고, 실행 시 그 CLI 로 위임된다

#### Scenario: CLI 미지정
- **WHEN** 오케스트레이션 `cliagents` 만 지정되고 실행 CLI 가 비어 있으면
- **THEN** 저장이 거부되거나 기본 CLI 가 명시적으로 표시된 채 저장되며, 어떤 CLI 로 실행될지 사용자가 알 수 있다

### Requirement: 모델과 실행 권한 옵션
시스템은 선택된 CLI 에 대해 사용할 모델과 실행 권한 수준(읽기 전용, 워크스페이스 쓰기 허용, 명령 실행 허용)을 선택할 수 있게 해야 한다(SHALL). 기본 권한 수준은 워크스페이스 쓰기 허용이어야 하며, 그보다 높은 권한은 명시적 선택을 요구해야 한다(SHALL).

#### Scenario: 기본 권한으로 실행
- **WHEN** 권한 수준을 지정하지 않고 업무를 실행하면
- **THEN** 실행은 워크스페이스 밖 쓰기와 임의 명령 실행이 허용되지 않은 상태로 수행된다

#### Scenario: 상향 권한 선택
- **WHEN** 사용자가 명령 실행 허용 수준을 명시적으로 선택하면
- **THEN** 그 설정이 저장되고, 업무 설정 화면에 상향된 권한이 사용 중임이 표시된다

### Requirement: CLI 가용성 조회
시스템은 각 CLI 의 설치 여부, 실행 파일 경로, 인증 가능 여부, 설치 안내 문구를 조회할 수 있는 경로를 제공해야 한다(SHALL).

#### Scenario: 설치된 CLI 조회
- **WHEN** 클라이언트가 가용성 조회를 요청하면
- **THEN** 등록된 CLI 목록과 각 CLI 의 설치 여부·인증 여부·설치 안내가 반환된다

#### Scenario: 미설치 CLI 표시
- **WHEN** 특정 CLI 가 실행 환경에 설치되어 있지 않으면
- **THEN** 조회 결과에서 해당 CLI 는 미설치로 표시되고 설치 방법 안내가 함께 반환되며, 선택 화면에서 선택 불가로 표시된다

### Requirement: 대체 실행 금지
시스템은 선택된 CLI 가 없거나 인증되지 않은 경우, 다른 CLI 나 다른 오케스트레이션으로 대체 실행하지 않아야 한다(SHALL NOT). 실행은 설치·인증 안내가 포함된 실패로 종료되어야 한다(SHALL).

#### Scenario: 선택한 CLI 미설치 상태에서 실행 시도
- **WHEN** 선택된 CLI 가 실행 환경에 없는 상태로 업무 실행이 시작되면
- **THEN** 업무는 즉시 실패로 기록되고 실패 사유에 어떤 CLI 가 없는지와 설치 안내가 포함되며, 다른 CLI 로 실행되지 않는다

#### Scenario: 인증되지 않은 CLI
- **WHEN** CLI 는 설치되어 있으나 인증 정보가 없어 실행이 거부되면
- **THEN** 업무는 인증 실패 사유로 종료되고, 어떤 자격 증명이 필요한지 안내된다

### Requirement: 새 CLI 추가 시 자동 노출
시스템은 새로운 CLI 에이전트가 라이브러리에 등록되면, 선택 목록과 가용성 조회 결과에 별도 화면 수정 없이 나타나야 한다(SHALL).

#### Scenario: 신규 CLI 등록
- **WHEN** 실행/아티팩트 표면을 지원하는 새 CLI 가 등록된 상태로 서비스가 기동되면
- **THEN** 가용성 조회 결과에 새 CLI 가 포함되고 사용자가 실행 CLI 로 선택할 수 있다
