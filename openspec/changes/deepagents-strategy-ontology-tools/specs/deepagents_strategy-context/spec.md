# deepagents_strategy-context — 실행 엔진의 전략 브리핑 주입과 온톨로지 탐색

## ADDED Requirements

### Requirement: 프로세스 실행 시 전략 브리핑이 자동으로 주입된다
프로세스 인스턴스 맥락이 있는 에이전트 실행에서, 실행 엔진은 에이전트 구성 시점에 현재 프로세스 정의의 전략 컨텍스트(기여 전략목표·KPI, 협업 대상, 관계 프로세스, 관련 스킬)를 스스로 조회해, 압축된 브리핑으로 에이전트의 실행 프롬프트에 SHALL 포함시켜야 한다. 이 주입은 에이전트의 도구 호출 여부와 무관하게 엔진이 SHALL 수행해야 하며, 조회 결과가 비어 있으면 브리핑 없이 진행한다. 브리핑이 항목 수 상한으로 잘린 경우, 심층 탐색 도구로 더 조회할 수 있음이 브리핑에 SHALL 표시되어야 한다.

#### Scenario: 전략에 연결된 프로세스의 워크아이템 실행
- **WHEN** 전략목표·KPI에 연결된 프로세스의 워크아이템을 에이전트가 실행하기 시작하면
- **THEN** 에이전트가 어떤 도구도 호출하기 전에, 기여 전략(중요도 포함)·협업 대상·관계 프로세스·관련 스킬을 담은 브리핑이 실행 프롬프트에 이미 포함되어 있다

#### Scenario: 전략에 연결되지 않은 프로세스의 실행
- **WHEN** 온톨로지상 아무 연결이 없는 프로세스의 워크아이템을 에이전트가 실행하면
- **THEN** 빈 브리핑 섹션 없이 실행이 정상 진행된다

### Requirement: 브리핑 조회 실패가 실행을 지연시키거나 중단시키지 않는다
전략 컨텍스트 조회가 실패하거나 제한 시간을 초과하면, 실행 엔진은 브리핑 없이 에이전트 실행을 SHALL 계속해야 한다. 브리핑은 최선 노력으로 제공되는 보조 정보이며 실행의 전제조건이 되어서는 안 된다(MUST NOT).

#### Scenario: 전략 서비스 미응답 상태에서의 실행
- **WHEN** 전략 서비스가 응답하지 않는 상태에서 프로세스 워크아이템 실행이 시작되면
- **THEN** 짧은 제한 시간 안에 브리핑 없이 에이전트 실행이 정상 진행된다

### Requirement: 애드혹 메인 에이전트의 위임 계획에 브리핑이 반영된다
서브태스크를 서브에이전트에게 위임할 수 있는 최상위(메인) 에이전트의 실행에서는, 위임 규칙 안내에 전략 브리핑의 관계 프로세스·에이전트·스킬을 서브태스크 위임 계획에 반영하라는 지침이 SHALL 포함되어야 한다. 온톨로지 조회 자체는 엔진의 브리핑 주입으로 이미 이행되므로, 에이전트는 브리핑에 나온 관계 대상을 확인하지 않은 채 위임 계획을 확정해서는 안 된다(MUST NOT). 서브에이전트가 구성되지 않은 실행에는 이 지침이 적용되지 않는다.

#### Scenario: 관계 대상이 있는 문제의 서브태스크 분해
- **WHEN** 서브에이전트가 구성된 메인 에이전트가, 브리핑에 관계 프로세스와 스킬이 표시된 상태에서 문제 해결 요청을 서브태스크로 분해하면
- **THEN** 확정된 위임 계획에 브리핑의 관계 프로세스·스킬을 참고하도록 지시하는 내용이 반영된다

#### Scenario: 관계 대상이 없는 경우의 진행
- **WHEN** 브리핑이 비어 있거나 관계 대상이 없는 상태에서 메인 에이전트가 서브태스크를 분해하면
- **THEN** 별도 참고 없이 위임이 정상 진행되며, 빈 브리핑이 실행을 막지 않는다

### Requirement: 심층 탐색 도구로 전략 컨텍스트를 조회할 수 있다
에이전트가 브리핑 범위를 넘어 탐색할 수 있도록, 시스템은 전략 컨텍스트 조회 도구를 SHALL 제공해야 한다. 이 도구는 프로세스 정의 id를 선택 인자로 받고, 생략 시 현재 실행 중인 프로세스 인스턴스의 프로세스 정의를 SHALL 자동 사용해야 한다. 실행 맥락도 없고 인자도 없으면 실패로 처리하지 않고 프로세스 정의를 지정하라는 안내를 SHALL 반환해야 한다. 응답은 전략 컨텍스트 조회 기능의 정렬 순서와 동기화 대기 표시를 그대로 유지해야 한다(MUST).

#### Scenario: 실행 중 인자 없이 호출
- **WHEN** 프로세스 인스턴스를 실행 중인 에이전트가 프로세스 정의를 지정하지 않고 전략 컨텍스트 도구를 호출하면
- **THEN** 현재 프로세스 정의 기준의 전략 컨텍스트가 반환된다

#### Scenario: 실행 맥락 없이 다른 프로세스를 지정해 호출
- **WHEN** 프로세스 실행 맥락이 없는 채팅에서 특정 프로세스 정의 id를 지정해 도구를 호출하면
- **THEN** 지정한 프로세스 기준의 전략 컨텍스트가 반환된다

#### Scenario: 실행 맥락도 인자도 없는 호출
- **WHEN** 프로세스 실행 맥락이 없는 채팅에서 프로세스 정의를 지정하지 않고 도구를 호출하면
- **THEN** 에이전트 실행이 중단되지 않고, 프로세스 정의를 지정해 다시 호출하라는 안내가 반환된다

### Requirement: 온톨로지 이웃 탐색 도구로 임의 노드를 탐색할 수 있다
시스템은 온톨로지 그래프의 임의 노드에서 관계를 따라 이웃을 확장 조회하는 탐색 도구를 SHALL 제공해야 한다. 이를 통해 에이전트는 브리핑·전략 컨텍스트에 나온 노드(전략목표, 프로세스, 에이전트, 스킬 등)에서 출발해 관계를 추가로 따라갈 수 있어야 한다(MUST).

#### Scenario: 브리핑에 나온 스킬의 관계 확장
- **WHEN** 에이전트가 브리핑에 표시된 스킬 노드 id로 이웃 탐색 도구를 호출하면
- **THEN** 그 스킬과 연결된 노드·관계 목록이 반환된다

#### Scenario: 존재하지 않는 노드 탐색
- **WHEN** 온톨로지에 존재하지 않는 노드 id로 이웃 탐색 도구를 호출하면
- **THEN** 에이전트 실행이 중단되지 않고, 노드를 찾을 수 없다는 결과가 반환된다

### Requirement: 탐색 도구의 조회 실패가 에이전트 실행을 중단시키지 않는다
탐색 도구들이 의존하는 서비스 호출이 실패하더라도, 시스템은 예외를 전파해 에이전트 실행을 중단시키지 않고 오류 내용을 담은 결과를 SHALL 반환해야 한다.

#### Scenario: 탐색 도구 호출 중 서비스 응답 실패
- **WHEN** 전략 서비스가 응답하지 않는 상태에서 에이전트가 탐색 도구를 호출하면
- **THEN** 에이전트 실행은 계속되고, 오류 내용을 담은 결과가 도구 호출 결과로 반환된다

### Requirement: 모든 테넌트·에이전트에 기본 적용된다
전략 브리핑 주입과 탐색 도구들은 테넌트별 활성화 설정 없이, 모든 테넌트의 모든 에이전트 실행에 기본으로 SHALL 적용·제공되어야 한다.

#### Scenario: 별도 설정 없는 테넌트의 실행
- **WHEN** 이 기능을 별도로 활성화한 적 없는 테넌트에서 전략에 연결된 프로세스의 워크아이템이 실행되면
- **THEN** 다른 테넌트와 동일하게 브리핑이 주입되고 탐색 도구를 사용할 수 있다
