## Why

지금 실행 중인 에이전트는 자신이 속한 프로세스 인스턴스가 회사 전략의 어느 목표·KPI에 기여하는지, 함께 협력해야 할 다른 에이전트·프로세스·스킬이 무엇인지 전혀 참고할 수 없다. 전략-프로세스-리소스-스킬 온톨로지 그래프와 그 조회 API는 이미 존재하지만, 조회 방향이 "KPI/전략 → 하위 원인 후보"로만 열려 있고 "프로세스 → 그것이 기여하는 전략"이라는 반대 방향의 총체적 조회는 없으며, 무엇보다 에이전트 실행 엔진에는 이 온톨로지가 전혀 연결되어 있지 않다.

특히 정해진 BPMN 흐름 없이 문제 해결형으로 진행되는 애드혹 프로세스에서는, 그 프로세스를 관장하며 서브태스크를 나누어 서브에이전트에게 위임하는 메인 에이전트가 전략적 판단의 유일한 주체다. 이 메인 에이전트에게는 서브태스크 분해 전에 관계된 프로세스·에이전트·지식을 온톨로지에서 참고하는 것이 선택이 아닌 의무여야 한다. 그런데 이 의무를 "도구를 주고 프롬프트로 호출을 지시"하는 방식으로 구현하면 이행이 LLM의 순응에 의존하게 된다 — 이 실행 엔진에서 프롬프트 문구만으로 새 기능 사용을 유도했을 때 신뢰도가 낮았던 선례가 이미 있다. 의무는 에이전트가 지키는 것이 아니라 엔진이 보장하는 구조여야 한다.

## What Changes

2계층 구조 — 엔진이 밀어 넣는 브리핑(push)과 에이전트가 끌어오는 탐색(pull) — 로 온톨로지를 실행에 연결한다.

- **전략 서비스에 통합 전략 컨텍스트 조회를 신설한다.** 프로세스 정의 하나를 기준으로 (1) 그것이 기여하는 전략목표·KPI(전략적 중요도 순), (2) 협업 대상 에이전트·사람, (3) 관계된 다른 프로세스, (4) 관련 스킬을 온톨로지 그래프에서 한 번에 모아 반환한다. 파편적 API 여러 개를 클라이언트가 조립하는 대신, 에이전트 실행의 순간에 필요한 전략 맥락 전체를 하나의 응답으로 제공한다.
- **실행 엔진이 전략 브리핑을 자동 주입한다.** 프로세스 인스턴스 맥락이 있는 모든 에이전트 실행에서, 엔진이 에이전트 구성 시점에 위 통합 조회를 직접 호출해 그 결과를 압축된 브리핑으로 실행 프롬프트에 넣는다. 서브태스크 분해가 시작되기 전에 전략 맥락이 이미 컨텍스트에 존재하므로, 애드혹 메인 에이전트의 온톨로지 참고 의무가 LLM의 순응이 아니라 엔진 코드로 보장된다. 조회 실패 시에는 브리핑 없이 실행을 계속한다(fail-open).
- **서브에이전트를 위임하는 메인 에이전트에게는 브리핑 반영 지침을 함께 준다.** 서브태스크 위임 계획을 세울 때 브리핑에 나온 관계 프로세스·에이전트·스킬을 반영하라는 지침을 위임 규칙 안내에 추가한다.
- **심층 탐색 도구를 제공한다.** 브리핑 범위를 넘는 탐색 — 다른 프로세스와의 비교, 특정 노드의 이웃 관계 확장, 실행 맥락이 없는 기획 단계 시뮬레이션 — 을 위해, 통합 전략 컨텍스트 조회와 온톨로지 이웃 탐색을 감싸는 에이전트 도구를 신설한다. 실행 맥락이 있으면 인자 없이 현재 프로세스를 자동 사용하고, 프로세스나 노드를 명시 지정할 수도 있다.

## Capabilities

### New Capabilities
- `strategy_process-strategic-context`: 프로세스 정의를 기준으로 기여 전략목표·KPI(중요도 순), 협업 대상 리소스, 관계 프로세스, 관련 스킬을 온톨로지 그래프에서 한 번에 모아 반환하는 통합 전략 컨텍스트 조회 기능.
- `deepagents_strategy-context`: 실행 엔진의 전략 브리핑 자동 주입(프로세스 맥락이 있는 모든 실행, fail-open)과, 에이전트가 온톨로지를 심층 탐색하는 도구 제공. 서브에이전트를 위임하는 메인 에이전트의 위임 계획에 브리핑을 반영시키는 것을 포함한다.

### Modified Capabilities
(없음 — 기존 공개 API 계약은 그대로 유지되고, 이번 변경은 신규 조회 기능·브리핑 주입·신규 에이전트 도구만 추가한다.)

## Impact

- services/strategy: 온톨로지 그래프를 프로세스 기준으로 총체 조회하는 신규 통합 API가 추가된다. 기존 `/api/ontology/*`, `/api/impact/*` 계약은 변경되지 않는다.
- services/deepagents: 에이전트 구성 시점에 전략 서비스를 호출해 브리핑을 프롬프트에 주입하는 로직과, 온톨로지 탐색 도구가 추가된다. 모든 테넌트·모든 에이전트 실행에 기본 적용된다.
- services/strategy와 services/deepagents 간 신규 서비스 간 호출(HTTP)이 추가된다 — 실행당 브리핑 조회 1회 + 에이전트의 선택적 탐색 호출.
