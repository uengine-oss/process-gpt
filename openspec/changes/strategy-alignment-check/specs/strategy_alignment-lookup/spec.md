# strategy_alignment-lookup — 텍스트 기반 전략 정합성 후보 조회

## ADDED Requirements

### Requirement: 자유 텍스트 설명으로 관련 전략 요소 후보를 조회할 수 있다
시스템은 자유 텍스트 설명(프로세스 초안 또는 스킬/프로세스 개선 내용 요약)과 tenant_id를 입력받아, 해당 테넌트의 전략맵에서 의미상 관련된 전략 목표·KPI 후보 목록을 SHALL 반환해야 한다. 각 후보에는 식별자, 이름, 관련 근거 요약이 포함되어야 하며(MUST), 목록은 관련도 순으로 SHALL 정렬되어야 한다. 응답에는 후보 생성 방식(LLM 기반인지 휴리스틱 폴백인지)이 SHALL 표시되어야 한다.

#### Scenario: 관련 전략 요소를 찾은 경우
- **WHEN** 클라이언트가 설명 텍스트와 tenant_id로 정합성 후보 조회를 요청하고, 해당 테넌트의 전략맵에 의미상 관련된 전략 목표 또는 KPI가 존재하면
- **THEN** 관련도 순으로 정렬된 후보 목록(각 후보의 식별자, 이름, 관련 근거 요약 포함)과 후보 생성 방식이 응답된다

#### Scenario: 관련 전략 요소를 찾지 못한 경우
- **WHEN** 조회 텍스트와 의미상 관련된 전략 목표·KPI가 테넌트의 전략맵에 존재하지 않으면
- **THEN** 빈 후보 목록과 "관련 항목 없음" 상태가 응답되며 오류가 반환되지 않는다

#### Scenario: 전략맵이 아직 수립되지 않은 테넌트
- **WHEN** 요청된 tenant_id에 대해 저장된 전략맵·BMC 캔버스가 하나도 없으면
- **THEN** 오류 대신 "관련 항목 없음"과 동일한 형태의 응답이 반환된다

### Requirement: 기존 프로세스 지정 시 이미 연결된 전략 요소를 후보와 구분해 반환한다
클라이언트가 기존 프로세스 정의 id를 함께 지정하면, 시스템은 그 프로세스가 온톨로지 그래프상 이미 연결된 전략 목표·KPI(프로세스 기준 전략 기여도 순방향 조회 결과)를 텍스트 기반 신규 후보와 구분되는 별도 항목으로 SHALL 포함해야 한다. 기존 연결 조회가 불가능한 환경(해당 조회 기능 미배포 등)에서는 조회를 실패시키지 않고, 기존 연결 확인이 생략되었음을 응답에 SHALL 표시해야 한다.

#### Scenario: 이미 KPI에 연결된 프로세스의 개선 내용 조회
- **WHEN** 이미 KPI와 연결된 프로세스 정의 id와 개선 내용 설명 텍스트로 정합성 후보를 조회하면
- **THEN** 응답에 기존 연결된 전략 목표·KPI가 신규 후보와 구분되는 항목으로 포함된다

#### Scenario: 기존 연결 조회가 불가능한 환경
- **WHEN** 기존 연결 조회 기능을 사용할 수 없는 환경에서 프로세스 정의 id를 지정해 정합성 후보를 조회하면
- **THEN** 텍스트 기반 후보만으로 응답이 반환되고, 기존 연결 확인이 생략되었음이 응답에 표시된다

### Requirement: 테넌트 간 데이터 격리
시스템은 요청에 포함된 tenant_id에 속하는 전략 데이터만 정합성 후보 조회 결과에 SHALL 포함해야 한다.

#### Scenario: 다른 테넌트의 전략 데이터 노출 차단
- **WHEN** 특정 tenant_id로 정합성 후보를 조회하면
- **THEN** 응답에는 동일한 tenant_id에 속한 전략 목표·KPI만 포함되고 다른 테넌트의 데이터는 포함되지 않는다
