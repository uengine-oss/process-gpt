# deepagents_process-generation-alignment-gate — 프로세스 생성 확정 전 전략 정합성 게이트

## ADDED Requirements

### Requirement: 프로세스 확정 전 전략 정합성 확인은 필수 선행 단계다
시스템은 프로세스 생성 흐름에서 새 프로세스 정의를 최종 확정하기 전에, 해당 프로세스 초안의 설명을 근거로 전략 정합성 조회를 SHALL 수행해야 한다. 정합성 조회를 생략한 채 프로세스 정의를 확정해서는 안 된다(MUST NOT). 이 의무는 전략 정합성 조회 도구가 사용 가능한 실행 환경에 적용되며, 조회 대상 서비스 호출이 실패하더라도 프로세스 생성 흐름 자체는 중단되지 않고 확인 불가 사실이 사용자에게 SHALL 안내되어야 한다.

#### Scenario: 확정 전 정합성 조회 수행
- **WHEN** 사용자가 프로세스 생성 흐름에서 프로세스 초안을 확정하려고 하면
- **THEN** 확정 이전에 프로세스 설명을 근거로 한 전략 정합성 조회가 수행된다

#### Scenario: 정합성 조회 서비스 호출 실패
- **WHEN** 정합성 조회가 의존하는 서비스가 응답하지 않는 상태에서 프로세스를 확정하려고 하면
- **THEN** 프로세스 생성 흐름은 중단되지 않고, 정합성 확인을 수행하지 못했다는 사실이 사용자에게 안내된다

### Requirement: 관련 KPI 후보 제시와 사용자 선택 기반 연결
정합성 조회 결과 관련 KPI 후보가 존재하면, 시스템은 후보를 사용자에게 SHALL 제시하고, 사용자가 선택한 KPI만 생성된 프로세스 정의와 SHALL 연결해야 한다. 사용자 확인 없이 후보를 자동으로 연결해서는 안 된다(MUST NOT).

#### Scenario: 후보 제시 후 사용자 선택 연결
- **WHEN** 정합성 조회 결과 관련 KPI 후보가 존재하고 사용자가 그중 하나를 선택하면
- **THEN** 선택된 KPI가 생성된 프로세스 정의와 연결된다

#### Scenario: 사용자가 후보 연결을 원하지 않는 경우
- **WHEN** 관련 KPI 후보가 제시되었지만 사용자가 연결하지 않기로 하면
- **THEN** KPI 연결 없이 프로세스 생성이 진행되고, 연결하지 않았다는 사실이 정합성 확인 결과에 기록된다

### Requirement: 관련 전략 요소가 없을 때 확인 후 진행
정합성 조회 결과 관련된 전략 목표·KPI가 없으면, 시스템은 그 사실을 사용자에게 SHALL 알리고, 사용자가 계속 진행할지 확인한 뒤에만 프로세스 정의 확정을 SHALL 진행해야 한다. 관련 전략 요소가 없다는 이유만으로 프로세스 생성을 차단해서는 안 된다(MUST NOT).

#### Scenario: 관련 전략 요소 없음 안내 후 진행
- **WHEN** 정합성 조회 결과 관련된 전략 목표·KPI가 없고 사용자가 계속 진행하기로 확인하면
- **THEN** 프로세스 정의 확정이 진행되고, "관련 항목 없음"을 확인하고 진행했다는 사실이 기록된다

### Requirement: 정합성 확인 근거가 프로세스 정의에서 조회 가능하다
시스템은 정합성 확인을 수행했다는 사실과 그 결과(연결된 전략 목표·KPI 식별자, 또는 "관련 항목 없음" 확인, 또는 확인 불가)를 생성된 프로세스 정의에서 조회 가능한 형태로 SHALL 남겨야 한다.

#### Scenario: 프로세스 정의에서 정합성 근거 확인
- **WHEN** 프로세스 생성이 완료된 뒤 해당 프로세스 정의를 조회하면
- **THEN** 정합성 확인 결과(연결된 전략 목표·KPI, "관련 항목 없음" 확인 여부, 또는 확인 불가 사유)를 확인할 수 있다
