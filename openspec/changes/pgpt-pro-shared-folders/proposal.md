## Why
- 지금 에이전트가 일하는 폴더는 실행 하나에만 묶여 있다. cli-agent 는 실행마다 `<작업 루트>/<테넌트>/<todo id>` 폴더와 worktree 를 만들고 72시간 뒤 지운다. deepagents 는 대화방·인스턴스별 폴더(`/workspace/.bpmn/<방>`)를 쓴다. 여러 사람이 함께 쓰고, 여러 실행이 이어서 고치는 "오래 사는 파일 공간" 이 없다.
- deepagents 테넌트 작업공간의 루트(`/workspace`)와 첨부 폴더(`/workspace/uploads/<uid>/…`)는 같은 테넌트의 모든 사용자 실행에 그대로 보인다. 사람 단위·폴더 단위로 공유 범위를 정할 수 없다.
- cli-agent 의 worktree 실행은 브랜치를 남기기만 한다("병합은 사람이 한다"). 같은 일을 여러 변형으로 시켜 보고 고른 것만 한꺼번에 기준본에 넣는 흐름, 그리고 그 변형을 다른 사람·에이전트에게 넘기는 흐름이 없다.
- 업무 인계(handover)는 산출물을 스토리지 파일 사본으로 넘긴다. 파일 묶음(폴더)과 그 작업 이력을 그대로 넘길 수는 없다.

## What Changes
- **공유 폴더**: 테넌트 안에 이름 있는 파일 공간을 만들고 등록한다. 구성원(사람·에이전트·역할)과 권한(소유·편집·실행·보기)을 둔다. 사람은 드라이브처럼 파일을 올리고 내려받고 미리보고, 이음오피스로 연다.
- **변형(variation)**: 폴더의 기준본(`main`)에서 갈라진 git 브랜치 작업 사본이다. 에이전트 실행마다, 프로세스 인스턴스마다, 또는 사람이 직접 만든다. 같은 일을 여러 변형으로 동시에 돌릴 수 있다.
- **일괄 반영**: 고른 변형들을 차례로 합쳐 기준본에 한 번에 반영한다. 충돌은 멈추고 보여 주며, 사람이 풀거나, 해결 에이전트에게 맡기거나, 파일별로 한쪽을 고른다.
- **프로세스 연결**: 프로세스 정의의 활동 설정에 폴더를 지정하면 그 인스턴스의 단계들이 폴더의 변형 위에서 실행된다. 앞 단계 변형을 이어받는 `@previous` 규칙은 지금의 cli-agent 규칙과 같다.
- **인계 연결**: 업무 인계에 "폴더 변형" 산출물을 실을 수 있다. 받는 사람·에이전트는 그 변형을 이어서 고치거나 새 갈래를 만든다. 인계 이벤트 로그에는 지금 형식 그대로 기록된다.
- **파일시스템 구조**: 안 2(폴더 = 살아 있는 디렉터리, 변형은 실행 때만 꺼내는 브랜치)로 확정했다(`design.md` 6장).
- **화면**: 폴더 목록(드라이브), 폴더(파일 트리 + 변형 목록 + 일괄 반영), 변형(main 과의 차이), 파일을 누르면 바로 여는 미리보기와 문서 카드.
- **색인**: 파일 목록 → 문서 카드 → 본문 색인의 3단계. 작은 폴더는 목록·카드만으로 사람 검색과 에이전트의 폴더 고르기를 한다. 카드는 memento 지식저장소의 문서 카드와 같은 모양이다.

## Capabilities
### New Capabilities
- `pgpt-pro_shared-folders`: 공유 폴더 등록·구성원 권한, 폴더·변형 화면과 미리보기, 변형 생성·인계, 일괄 반영, 프로세스 인스턴스 연결, 색인·검색

### Modified Capabilities
없음. `cliagents_product-worktree-execution`(저장소 worktree 실행)과 `pgpt-pro_agent-workroom`(작업실)의 계약은 그대로 두고 그 위에 얹는다. 작업실은 폴더 변형도 열 수 있게 늘어나지만 기존 요구사항은 바뀌지 않는다.

## Impact
- **pgpt-pro 서버(BFF)**: 폴더·변형·반영 API, 폴더 저장소 관리(모든 git 조작은 서버가 한다), 작업실의 열 수 있는 대상에 폴더·변형 추가, 구성원 권한 확인.
- **pgpt-pro 화면**: 폴더 목록·드라이브 화면, 변형 비교(파일 목록·텍스트 차이·문서 미리보기), 일괄 반영 화면, 인계 대화상자의 폴더 변형 선택.
- **pgpt-pro DB**: `pro_folders`, `pro_folder_members`, `pro_folder_variations`, `pro_folder_integrations`(pgpt-pro 전용 테이블, process-gpt 핵심 테이블은 바꾸지 않음).
- **process-gpt 서비스**: 추천안 기준으로 cli-agent 는 바꾸지 않는다(폴더 저장소를 `project_repo` 로 넘긴다). deepagents 는 바꾸지 않는다(변형 작업 사본을 실행 폴더 안에 둔다). 폴더별 샌드박스 격리를 고르면 deepagents 수정이 필요하다.
- **저장소**: 폴더 저장소 루트(호스트 디렉터리)와 백업용 스토리지 버킷.
- **memento(선택)**: 본문 색인 단계에서만 폴더 문서를 지식저장소에 등록한다.
