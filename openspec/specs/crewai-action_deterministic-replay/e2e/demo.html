PROCESS GPT

실행 경로 고착화
(Deterministic Replay)

AI 에이전트가 한 번 성공적으로 수행한 업무를 Python 코드로 고착화하고,
이후에는 LLM 추론 없이 매번 똑같이 실행합니다.

문제LLM 에이전트는 강력하지만, 매번 다르게 행동할 수 있다

기업 업무에서 "지난번엔 됐는데 이번엔 다르게 처리했다"는 것은 치명적입니다.

LLM 재량 실행의 리스크

  • 같은 요청에도 실행 경로가 달라질 수 있음 (할루시네이션)
  • 매 실행마다 LLM 추론 비용·지연 발생
  • 무엇이 실행될지 사전 검증 불가

Process GPT의 답 — 고착화

  • 1차 실행의 도구 호출 이력을 기록
  • 검증된 경로를 파라미터화된 코드로 고착
  • 2차 실행부터는 AI가 아니라 코드가 실행
LLM 1차 실행 (탐색·판단)
→
이벤트 기록 (tool_usage_finished)
→
Python 코드 고착화
→
DETERMINISTIC n차 실행 (LLM 0회)

왜 중요한가 — 비즈니스 가치

  

    
    
      
  • ✅ 정확성 — 한 번 검증된 실행 경로가 그대로 재현됩니다. 두 번째부터는
          할루시네이션이 개입할 여지가 없습니다.
    • 
      
  • 💰 비용·속도 — 반복 업무에서 LLM 추론이 사라집니다.
          이번 데모에서도 실행 시간이 5.2s → 3.1s로 줄고 추론 호출은 3회 → 0회.
    • 
      
  • 📋 감사 가능성 — 업무가 "프롬프트"가 아니라 읽고 검토할 수 있는 코드로
          남습니다. 무엇이 실행되는지 사전에 알 수 있습니다.
    • 
      
  • 🧠 프로그래밍 없는 자동화 — 개발자가 코드를 짠 것이 아닙니다.
          AI가 일하는 것을 지켜본 시스템이 스스로 코드를 만들었습니다.
    • 
      
  • 🔁 되돌리기까지 — 같은 메커니즘으로 보상(undo) 코드도 생성되어,
          재작업 시 이전 부수효과를 안전하게 되돌립니다.
