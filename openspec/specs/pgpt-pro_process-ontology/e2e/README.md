- Gmail: 실제 메일함으로는 시험하지 않는다(연결된 계정이 장진영 본인). Gmail API 와 같은 모양으로 답하는 모의 서버(`PRO_GMAIL_API`)로 `test/ontology-gmail.test.js`
- Ontological DB: 네이티브 PG16 :27532 + Bolt :27787, 데이터베이스 `pgpt_onto`, 회사마다 그래프 `pgpt_<테넌트>`(설치 때만 SQL로 그래프 · 타입 · 시점 속성을 만들고, 실행 중에는 Bolt 의 Cypher 만 쓴다)
- Process GPT 공용 엔진: completion :8099(자연어 조건 판단), deepagents :8888(엑셀 스킬), Supabase :54321/54322
- 모델: 회사 게이트웨이 `frentis-ai-model`(메일 읽기 · 이름 맞추기 · 시작 일 · 일 정의 초안 · 점검). AI 후보 판단은 스킬 기준값 `candidates.judge` 대로 이 기기의 claude CLI 로 `claude-fable-5-2`(없으면 게이트웨이 모델)
- 11-14 실제 메일 · 대화 기록 시험: 데모와 따로 둔 실제 메일 테넌트(데이터는 공개하지 않음, 수치만 아래에)

## 실행
```bash
cd server
node scripts/ax-demo.mjs --reset --seed
PRO_API=http://ax.localhost:8790 node test/ontology-map.e2e.mjs      # S1 지도 그리기(메일 읽기 포함 약 15분)
PRO_API=http://ax.localhost:8790 node test/ontology-run.e2e.mjs      # S2 어디서든 시작(업무 에이전트 포함 약 6분)
PRO_API=http://ax.localhost:8790 node test/ontology-archive.e2e.mjs  # S1b 메일 보관함(S1 뒤)
PRO_API=http://ax.localhost:8790 node test/ontology-review.e2e.mjs   # S3 고정 · 노화 · 검토(끝에 되돌림)
PRO_API=http://ax.localhost:8790 node test/ontology-roles.e2e.mjs    # S4 역할과 습관 · 일의 방법 → 스킬(에이전트 세 번, 약 10분)
PRO_API=http://ax.localhost:8790 node test/ontology-triggers.e2e.mjs # S5 승격 단계 · 제안 카드 · 타이머 · 메일의 예약 제안
node --test test/ontology-*.test.js   # 단위 34: 판단 사례(ontology-cases.json) · 엑셀 칸 · 사건/역할 · 지도 화면 · 메일 본문/첨부/주기 · Gmail 모의 서버
node --test --test-concurrency=1 test/ontology-*.test.js   # 11-14: 단위 53(+ 스킬 판 · 회사 사람 · Gmail 쿼터 · 문서 · 양식 칸 · 카카오톡 · 건 이어 묶기 · 근거 · 깨진 이름 · AI 후보 규칙 · 단순 프로세스)
node --test --test-concurrency=1 test/ontology-refine.test.js test/ontology-runmode.test.js test/ontology-steprule.test.js test/ontology-formats.test.js   # 11-16: 단위 56(다듬기 16 · 실행 방식 14 · 단계 규칙 11 · 양식과 형식 규칙 15)
cd ../e2e && PGPT_URL=http://ax.localhost:5191 API_URL=http://ax.localhost:8790 PGPT_TENANT=ax-demo PGPT_DB_URL=<공용 DB 주소> npx playwright test tests/feature/process-ontology.spec.js
```

### Ontological 에서 만난 제약(원본 저장소에 알릴 것)
- 시간 이력을 켠 키 있는 타입에서 `UNWIND … MERGE` 로 이미 있는 노드를 고치면 키 중복(`uq_…_p_key`)이 난다 → `UNWIND MATCH … SET` 과 `UNWIND CREATE` 로 나눠 쓴다.
