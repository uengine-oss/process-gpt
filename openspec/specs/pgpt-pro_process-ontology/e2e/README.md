## 실행 환경
- Process GPT Lite 기능 브랜치 `feat/process-ontology`(uengine-oss/process-gpt-lite), 서버 :8790(`PRO_BACKGROUND=0`), 화면 :5191(개발) · :5192(녹화용 고정 빌드)
- 데모 테넌트 `ax-demo`(`http://ax.localhost:…`): 장진영(제안팀장 · 관리자), 이도윤(영업), 김민지(디자이너), 박서연(재무 담당). 초기화 `node server/scripts/ax-demo.mjs --reset --seed`, 실행 흔적만 지우기 `--clean-runs`
- 데모 메일함: `server/scripts/fixtures/ax-demo-mailbox.json`(90일, 483통 — 뉴스레터 · no-reply · 일정 초대 37통 포함, 견적서 양식 `ax-demo-templates/견적서_양식.xlsx`). 정답 흐름은 같은 파일의 `truth`
- Ontological DB: 네이티브 PG16 :27532 + Bolt :27787, 데이터베이스 `pgpt_onto`, 회사마다 그래프 `pgpt_<테넌트>`(설치 때만 SQL로 그래프 · 타입 · 시점 속성을 만들고, 실행 중에는 Bolt 의 Cypher 만 쓴다)
- Process GPT 공용 엔진: completion :8099(자연어 조건 판단), deepagents :8888(엑셀 스킬), Supabase :54321/54322
- 모델: 회사 게이트웨이 `frentis-ai-model`(메일 읽기 · 이름 맞추기 · 시작 일 · 일 정의 초안 · 점검)

```bash
cd server
node scripts/ax-demo.mjs --reset --seed
PRO_API=http://ax.localhost:8790 node test/ontology-map.e2e.mjs      # S1 지도 그리기(메일 읽기 포함 약 15분)

```

### 시험을 돌리며 고친 결함
- 지난 실행의 같은 이름 파일이 작업 공간에 있으면 에이전트가 확인만 하고 끝나 단계가 실패했다 → 이 건의 파일을 새로 만들게 했다.
- LibreOffice 가 글꼴이 섞인 칸을 rich text 로 저장해 점검이 빈칸으로 읽혀 6개 중 5개가 ✗ 였다 → 사람이 보는 글자로 읽는다(단위 시험).
- 조건부 노화로 바꾸며 「최근 0일 동안」으로 나왔다 → 실제 날 수.
- 서버가 도는 동안 바깥에서 그래프를 지우면(데모 초기화) 지도가 오류였다 → 그래프를 다시 만들어 빈 지도(S1 첫 단계에 추가, 손으로 확인: 초기화 직후 200 · 일 0).
- 메일 읽기 첫 몇 분이 「0통 읽음」에 멈춰 보였다 → 거른 메일을 곧바로 세고, 채팅 이름 맞추기 단계라고 알린다.

### Ontological 에서 만난 제약(원본 저장소에 알릴 것)
- 시간 이력을 켠 키 있는 타입에서 `UNWIND … MERGE` 로 이미 있는 노드를 고치면 키 중복(`uq_…_p_key`)이 난다 → `UNWIND MATCH … SET` 과 `UNWIND CREATE` 로 나눠 쓴다.
- `MERGE … WITH … MERGE (관계)` 를 한 문장에 쓸 수 없다, `id` 속성은 내부 id 와 겹친다(→ `key`), 숫자 속성은 float8 로 선언해야 한다, 라벨 없는 패턴은 시점 질의를 거절한다.
