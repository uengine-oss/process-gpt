# 대화 맥락 라우팅 검증 (e2e)

## 실행 환경
- Docker 인프라: Supabase(local)
- 소스 실행 서비스: context-router(8895), 참조 판단 서버(8896), deepagents(8888), pgpt-pro BFF(8787, `PRO_CONTEXT_ROUTER_URL=http://127.0.0.1:8895`), pgpt-pro 웹(5180)
- 맥락 저장 테이블: `services/context-router/sql/001_context_threads.sql`

## 시나리오 (한 채팅창, 메시지 4개)
1. "경제사냥꾼 유튜브 채널 최근 영상 3개 제목 알려줘" → 맥락 없음, 새 대화
2. "다음 주 28~30일 부산 출장, 해운대 근처 숙소 추천" → 판단 모델이 망설여 logprob 으로 에스컬레이션, 새 주제
3. "아까 그 채널 두 번째 영상은 무슨 내용이야?" → 판단 모델이 유튜브 대화로 이어 붙임
4. "숙소는 바다 보이는 곳이면 좋겠어" → 판단 모델이 출장 대화로 이어 붙임

## 증거

## 맥락이 많을 때 (후보 좁히기 · 압축 · 재판단)

### 측정 (`services/context-router/eval/scale.py`)
- 라우팅 22문항 중 애매한 1문항을 뺀 21문항에, 실제 맥락 5개(출장 10시간 전, 유튜브 3일, SNS 12일, 부가세 20일, 팟캐스트는 진행 중 작업)와 무관한 대화 0·25·100·300개(지난 25일에 고르게, 대부분 실제 맥락보다 최근)를 섞었다.
- 무관한 대화에는 일부러 겹치는 함정(다른 유튜브 채널, 서울 출장, 종합소득세, 사내 팟캐스트)을 넣었고, "새 주제" 문항과 같은 주제(노트북, 엑셀, 환율)는 넣지 않았다. 같은 주제의 대화가 있으면 그것을 잇는 것이 정답이 되기 때문이다.
- 비교 방식
  - `recent8`: 기존 — 최근 8개, 전체 요약
  - `all25`: 문자 선택지 한계까지 최근 25개, 전체 요약
  - `lex6`: 라우터 경로(`route`)에서 단어 겹침만으로 좁히기
  - `route6`: 현재 라우터 — 단어 겹침 + 의미(bge-m3) 좁히기, 나이별 압축, 근거 없는 판단 모델 선택 재판단
- 판단 정책은 운영과 같다: judge(Qwen3-4B-Instruct, MPS) → logprob(frentis) → JSON, 확신도 0.9 미만 에스컬레이션

| 무관한 대화 | recent8 | all25 | lex6 | route6 |
|---|---|---|---|---|
| 0 | 81% · 0.64s | 81% · 0.72s | 90% · 0.84s | 90% · 0.94s |
| 25 | 52% · 0.96s | 90% · 2.53s | 86% · 0.88s | 90% · 0.93s |
| 100 | 57% · 1.05s | 71% · 2.56s | 86% · 0.90s | 90% · 0.89s |
| 300 | 52% · 0.97s | 57% · 2.28s | 81% · 0.85s | 95% · 0.80s |

(정확도 · 판단 지연 중앙값. 판단 모델이 읽는 후보 설명은 route6 약 450자, all25 약 1,600자)

- 남은 오답은 대부분 확신이 없어 옮기지 않은 `stay` 다.
- 300개에서 "세금계산서 발행 기한" 은 부가세 대화와 겹치는 단어가 없고 최근 200개 밖이라 후보에 들지 못했다. 저장소 쪽 벡터 검색(pgvector)이 후속 과제다.
- 증거: `scale.json`(문항별 결과), `scale.log`, `scale-report.html`, `unit-tests.log`(18건 통과)

### 실제 화면 (pgpt-pro, 사용자 맥락 120개)
- 사용자 `pro-route4` 에게 지난 25일의 대화 120개(부가세 20일 전, 출장 10시간 전, 유튜브 3일 전 + 무관한 117개)를 넣고 통합 채팅에서 세 메시지를 보냈다.

| 메시지 | 결과 | 판단 |
|---|---|---|
| 부가세 납부했어, 리마인드 꺼줘 | `continue` 10월 부가세 납부 | judge 1.00 |
| 오늘 점심 메뉴 추천해줘 | `new` | judge 망설임 → logprob 0.999 |
| 숙소는 바다 보이는 곳이면 좋겠어 | `continue` 부산 출장 준비 | judge 망설임 → logprob 0.99 |

- 같은 데이터로 `POST /route` 를 직접 불렀을 때는 "숙소" 에서 판단 모델이 근거 없는 대화를 0.99 로 골랐고, 재판단으로 출장 대화가 됐다(`notes`: "judge picked … with no evidence in the message; re-decided"). "세금계산서 발행 기한도 같이 확인해줘" 는 의미 유사도로 부가세 대화에 이어졌다.
- 시연 영상: `../docs/context-router-scaling-demo.mp4`(1분 42초, 나레이션)
