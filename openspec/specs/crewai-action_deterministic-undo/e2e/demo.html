Undo — AI가 실행한 업무,
버튼 하나처럼 되돌리기

에이전트가 데이터베이스에 남긴 변경을, 기록된 실행 이력으로부터 만든 역연산(undo) 코드로 안전하게 취소합니다.
재작업 시에는 undo → 새 값으로 재실행이 자동으로 이어집니다.

문제AI가 이미 실행해버린 업무, 잘못됐다면?

1편에서 에이전트는 iPhone 입고 60을 DB에 반영했습니다(재고 20 → 80). 그런데 입고 수량이 40이 맞았다면? 문서 편집처럼 Ctrl+Z가 필요합니다.

어려운 점

  • 부수효과가 이미 실제 DB에 반영됨 (UPDATE·INSERT)
  • 사람이 수동 복구하면 실수·누락 위험
  • 어떤 실행의 흔적만 골라 되돌려야 함

Process GPT의 답 — 이력 기반 Undo

  • 모든 도구 호출이 이벤트 로그로 남아 있음
  • 로그로부터 역연산 코드를 자동 생성·보존
  • 실행 시 LLM 없이 결정론적으로 원복
실행 이력 (이벤트 로그)
→
역연산 undo 코드 생성·보존
→
UNDO 부수효과 원복
→
REDO 새 값으로 재실행

왜 중요한가 — 시도하고, 검증하고, 안심하고 되돌린다

  

    
    
      
  • ↩️ 안전망 — AI 자동화의 가장 큰 두려움은 "잘못 실행되면?"입니다.
          모든 실행이 이력으로 남고, 이력이 곧 되돌리기가 됩니다.
    • 
      
  • 🎯 정밀 복구 — 백업 복원처럼 전체를 되돌리는 게 아니라,
          해당 실행의 부수효과만 골라 원복합니다.
    • 
      
  • 🔁 재작업 자동화 — 운영자가 "다시 수행하기"를 누르면
          undo → 새 값 재실행이 사람 개입 없이 이어집니다.
    • 
      
  • 📋 감사 추적 — 무엇이 실행됐고, 무엇이 취소됐는지
          전부 코드와 이벤트로 남습니다.
