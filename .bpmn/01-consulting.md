# 컨설팅 요약

**프로세스 수**: 1개
**프로세스명**: RFP·입찰 파이프라인 관리
**한 줄 설명**: 신규 입찰·RFP 발굴부터 제안서 작성·내부 승인·제출·수주 결과 등록까지를 표준화해, 입찰 파이프라인 금액과 수주율 지표를 뽑을 수 있게 하는 프로세스.

## 합의된 흐름 초안
1. RFP 발굴·등록 (역할: 영업담당자) — 발주기관, 예산 규모, 마감일, 요구사항 요약을 등록하며 프로세스 시작
2. 참여 여부 검토 (역할: 영업팀장) — 분기: 참여 → 3단계 / 미참여 → 사유 기록 후 종료
3. 제안서 작성 (역할: 제안팀) — 기술·가격 제안 내용 작성
4. 내부 검토·승인 (역할: 영업팀장) — 분기: 승인 → 5단계 / 반려 → 3단계로 되돌아감
5. 제출 (역할: 영업담당자) — 발주기관에 제안서 제출, 제출일 기록
6. 결과 등록 (역할: 영업담당자) — 분기: 수주 → 계약 체결 안내 후 종료 / 탈락 → 탈락사유 기록 후 종료

## 역할 / 담당자
- 영업담당자: RFP 발굴·등록, 제출, 결과 등록
- 영업팀장: 참여 여부 판단, 제안서 내부 검토·승인
- 제안팀: 기술·가격 제안서 작성

## 입력/산출 데이터 (파악된 것)
- RFP 발굴·등록: 산출 (발주기관, 예산 규모, 마감일, 요구사항 요약)
- 참여 여부 검토: 산출 (참여 여부, 미참여 사유)
- 제안서 작성: 산출 (제안서 내용)
- 내부 검토·승인: 산출 (승인 여부, 반려 사유)
- 제출: 산출 (제출일)
- 결과 등록: 산출 (수주 여부, 탈락 사유)

## 메모 / 미결 사항
- BSC 전략 인터뷰 연계: 이 프로세스의 '예산 규모' 누적치가 F1(라이선스+SI 매출 성장)의 선행 KPI "입찰·제안 파이프라인 금액"을, '수주 여부' 비율이 C1(대기업 고객 기반 확대·유지)의 선행 KPI "RFP·입찰 수주율"을 직접 생산한다.
- 계약 체결 자체(계약서 작성·서명)는 별도 프로세스("장기 유지보수·재계약 관리") 영역으로 분리 — 이번 프로세스는 결과 등록에서 종료.
